# Proyecto Final - Programación Web

## Descripción del proyecto

Este proyecto consiste en una aplicación web desarrollada para la materia de Programación Web.

La aplicación permite visualizar y registrar caricaturas utilizando una interfaz web dinámica conectada a una base de datos MySQL mediante Node.js y Express.

El sistema cuenta con funcionalidades para:

- Mostrar una lista de caricaturas registradas
- Visualizar detalles individuales de caricaturas
- Registrar nuevas caricaturas mediante formularios
- Gestionar información desde una base de datos

Además, el proyecto incluye diseño visual personalizado con HTML, CSS y JavaScript.

## Instalación y ejecución

### 1. Clonar el repositorio

```bash
git clone https://github.com/canelaxo/Proyecto-Final-Programaci-n-Web.git
```

### 2. Entrar al proyecto

```bash
cd Proyecto-Final-Programaci-n-Web
```

### 3. Instalar dependencias

```bash
npm install
```

### 4. Ejecutar el servidor

```bash
node server.js
```

### 5. Abrir en el navegador

```bash
http://localhost:3000
```
